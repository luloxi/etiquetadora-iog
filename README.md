# Etiquetas 10×15 — Unnion LP4206D

Web para componer e imprimir etiquetas de **10 cm × 15 cm** en la Unnion LP4206D.

La impresión usa el diálogo del navegador y el driver local (Windows o Mac). Vercel no puede hablar por USB con la impresora.

- Home: compositor + vista previa
- [Configurar driver](setup.html): Windows, Mac, [descarga de drivers](https://drive.google.com/drive/folders/1R4AVpFzwgTYClNcxOHVyc2KqmyZSLLeo?usp=sharing) y cómo cargar el rollo
- [Reponer etiquetas 10×15](https://listado.mercadolibre.com.ar/etiquetas-termicas-100x150) en Mercado Libre
