# Etiquetas 10×15 — 4BARCODE 4B-2054G

Web para componer e imprimir etiquetas de **10 cm × 15 cm** en la 4BARCODE 4B-2054G.

La impresión usa el diálogo del navegador y el driver local (Windows o Mac). Vercel no puede hablar por USB con la impresora.

- Home: compositor + vista previa
- [Configurar driver](setup.html): Windows, Mac y cómo cargar el rollo
